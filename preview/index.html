Everywhere you look

One palette, eleven surfaces. The point isn't a themed app — it's that nothing breaks the spell.

Plasma shell

Catppuccin Mocha base, Sugar Plum selection color, floating glass panel, blurred popups, rounded window decorations.

Nushell

Your existing pastel-goth prompt, retuned to the system palette: lilac path, candy git branch, periwinkle clock, orchid λ.

fish

A conf.d snippet, not a rewrite: colors, eza, fzf, bat, and a matching fastfetch greet.

Ghostty

Custom ANSI palette from the five pastels, candy cursor, translucent background, Nunito title.

Dolphin + Ark

Papirus folders in candy pink, plus real 7z right-click actions: compress, compress with password, extract here, extract to…

Screenshots

Print for region, Shift+Print full screen, Alt+Print active window — all open in satty for arrows and blur.

btop

Candy, mint, and seafoam graphs on plum. CPU, memory, disk, temp — readable at a glance.

Neovim

Catppuccin Mocha with Sugar Plum overrides for the cursor line, search, and statusline accents.

bat · eza · fzf

Environment colors in one shell snippet so CLI output stops looking like a different machine.

GTK apps

Dark Breeze base, Papirus icons, Nunito. Honest limit: libadwaita apps won't fully recolor without a GTK theme.

Login screen

Plasma Login gets the same wallpaper and dark treatment. Its 6.8 config only exposes wallpaper, not a full theme.

Limine

Pastel wallpaper, plum backdrop, candy/lilac text palette, and a small sugar plum ♡ branding line.

Boring on purpose

This is a dotfiles repo with an installer, not a pile of commands someone pasted once. It keeps a ledger of every file it touches, backs up what was there, and can put it all back.

  1. Install. ./install.sh checks packages, backs up configs, writes marked blocks, and applies the theme.
  2. Move. Clone the same repo on another CachyOS/Arch box and run it again. Wallpapers and scripts travel with it.
  3. Undo. ./install.sh --revert restores the backups, removes only its own files, and switches Plasma back to Breeze.
